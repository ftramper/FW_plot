# Example output

These PDFs were generated for the FASTWIND model `T40g37R15N60`.

- `T40g37R15N60_line_profiles_R7500_vsini100.pdf`:
  resolving power `R = 7500`, `v sin i = 100 km/s`, no added noise.
- `T40g37R15N60_model_diagnostics.pdf`:
  model-structure and convergence diagnostics.

The line-profile example corresponds to:

```bash
python plot_fw_model.py T40g37R15N60 7500 100
```
